# Architecture Decision Records (ADRs)

This file logs architecture decisions for the XSelf Product Supply Intelligence System.
Each decision is recorded as a numbered ADR using the template below. Decisions are
append-only: to change a decision, add a new ADR that supersedes the old one (never edit
history).

- **Status values:** Proposed · Accepted · Superseded · Deprecated · Rejected
- **Numbering:** ADR-0001, ADR-0002, … (zero-padded, sequential)
- No decisions have been recorded yet. The template is provided for future use.
