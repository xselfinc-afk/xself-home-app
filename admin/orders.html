Xself Home — Admin Orders

Admin operations console · Status updates, custom payment links, admin approval, BOL upload

Refunds happen in the Stripe dashboard. Approvals are NOT reversible from this UI yet. All actions are audit-logged.

Setup

Paste your Supabase project URL and the project's public anon key. Both are public values from the project — never the service role key. Persisted in this browser's localStorage.

Sign in

Use the Supabase email + password for your admin user. Your email must be present in the admin_users table.
